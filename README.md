# Windows Optimizer

A one-click tool to tune Windows 10 and 11 for speed and gaming.

## Download

Get **WindowsOptimizer.exe** from the [latest release](https://github.com/Teddymazrin/WindowsOptimizer/releases/latest), then run it. It asks for administrator rights because it changes system settings.

Windows SmartScreen may warn that the app is unrecognized. Click **More info**, then **Run anyway**.

The app checks this page for new versions and offers an **Update Now** button when one is out.

## What it does

**Optimizations** (apply all at once, or one by one)
- Disable automatic maintenance, menu show delay, notifications and Game Bar
- Classic right-click menu and no Widgets (Windows 11)
- High Performance power plan
- Remove Windows bloatware
- Disable UAC (optional)

**Quick installs:** NVIDIA drivers, Epic Games Launcher, Steam, 7-Zip, Discord, Speccy

**Repair and cleanup:** SFC scan, DISM scan, clear temp files, Disk Cleanup, uninstall the NVIDIA driver

**Restart into:** BIOS / UEFI, Recovery Mode, Safe Mode

## Use at your own risk

This tool changes the registry and system settings. Create a restore point before you apply optimizations.
